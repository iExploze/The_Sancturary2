# The Sancturary

> Working title for a 1–4 player co-op horror game set inside a large abandoned institution.

## Overview

Players enter an abandoned building, explore its rooms, complete objectives, and escape roaming monsters. The game focuses on tense chases, limited information, teamwork, and using the building's decaying security systems to survive.

The project is a 3D reimagining of an earlier 2D prototype created by Ian Zhang and Vlad Ign.

## Core ideas

- First-person co-op horror for 1–4 players
- A connected abandoned building with multiple routes and recognizable areas
- Monsters with distinct behaviours, strengths, and weaknesses
- Security cameras and remotely controlled doors that players can use against monsters
- Exploration objectives that force players to leave safe areas
- Limited visibility, environmental storytelling, and reactive audio
- Short, replayable matches built around panic, coordination, and escape

## Initial prototype scope

The first playable version should contain:

- One small building wing
- One security room with several camera feeds
- Two remotely controlled doors
- One monster
- One objective and one escape route
- One to four networked players
- A complete 10–15 minute gameplay loop

## Technology

- Unity 6.3 LTS
- Universal Render Pipeline
- C#
- Blender for characters and environments
- Unity Netcode for GameObjects and Multiplayer Services
- GitHub and Git LFS

## Team

- Ian Zhang — programming, game design, systems, and multiplayer

## Status

Pre-production. The immediate goal is to build a small graybox multiplayer prototype and prove that the chase and security-camera mechanics are fun before expanding the map or monster roster.
